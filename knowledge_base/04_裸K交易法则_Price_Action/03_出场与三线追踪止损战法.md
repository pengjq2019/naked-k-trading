# 出场与三线追踪止损战法

## 1. 常规出场：目标关键位与悲观原则
- **目标位锚定**：以行进方向上的下一个重要水平关键位作为初始目标。
- **让利悲观原则**：市场极少精准触及绝对高低点即刻反转。为确保利润落袋，止盈目标必须**向内侧收敛预留一定点位空间**（例如外汇让给市场 $5 \sim 15$ 个点，黄金原油让出合理波动缓冲），杜绝因为差 1 个点未扫止盈而坐过山车。

---

## 2. 进阶出场战术：三线战法 (Three-Bar Trailing Stop)

### (1) 战术原理与适用场景
- **动能原理**：在强势单边趋势中，健康的波段回踩一般不会超过连续 3 根K线的极值。一旦击穿前 3 根K线的反向极值，说明该波段动能已经减竭或出现反转。
- **核心目的**：在不放大初始风险的前提下，放弃固定止盈限制，完全由市场走势决定获利上限，用于**博取翻倍以上的单边超级大行情**。
- **适用行情**：行情走势流畅、中大阳/阴线连续推进的单边趋势。严禁在影线交错、红黑相间的震荡市中使用。

### (2) 具体执行规则
1. **初始阶段**：
   - 突破信号入场，不设置止盈。
   - 初始止损严格设在信号K线的极值影线后方。
2. **移动跟踪阶段**：
   - 当入场后走出第 1 根、第 2 根K线时，维持初始止损不动。
   - 当第 3 根K线收盘成型后，将止损位**移动至这最新 3 根K线的极值点**：
     - 做空单：移动至最新 3 根K线的最高价上方。
     - 做多单：移动至最新 3 根K线的最低价下方。
   - 之后每收出一根新K线，重新取包含该新K线在内的最新 3 根K线极值，动态跟进止损。
3. **止损单向锁定原则**：
   - **止损位只能单向缩小风险或锁定利润，严禁反向放大**。若最新 3 根K线的极值导致止损回撤放大，则维持原最严苛止损位不变。
4. **离场触发**：
   - 价格出现较深回调，触碰到最新设定的 3 线止损位，自动平仓锁定大额波段利润。

### (3) 实战优劣权衡
- **优势**：盈亏比可轻松从 $1.5:1$ 扩展到 $3:1$ 甚至 $5:1$ 以上；彻底消除主观猜顶猜底的踏空心理。
- **代价**：若行情单根K线打到原关键位目标后发生急跌急涨，三线战法可能会回吐该部分利润甚至止损，属于“以既得利润博取未知暴利”的专业博弈。
