# K线四要素与本质轨迹

## 1. K线四要素构成
任何K线（或美国线）均由特定周期内的四个核心价位决定：
- **开盘价 (Open)**：周期起点价格
- **最高价 (High)**：周期内多头推升的极限
- **最低价 (Low)**：周期内空头打压的极限
- **收盘价 (Close)**：周期终点价格，多空博弈在该周期的最终裁决

开盘价与收盘价构筑**实体**，最高价与最低价延伸出**影线**（上影线、下影线）。

## 2. K线形态的分类与力量对比
### (1) 单根K线
- **大阳线 / 大阴线**：实体长、影线极短。代表单方力量占据绝对统治地位，通常属于单边趋势的启动或延续，切忌逆势摸顶抄底。
- **中阳线 / 中阴线**：存在一定实体与影线，属于多空经历拉锯后一方稳步推进的产物。
- **小阳线 / 小阴线 / 十字星**：实体极窄，反映市场观望情绪浓厚、资金流动性降低，或处于重大数据/行情决战前夕的均衡状态。若出现在关键位，十字星具备潜在变盘意义；若出现在通道中继，则无操作价值。
- **流星线 / 倒锤线**：长上影线、实体极小。上影线是多头冲高遇阻被空头暴力砸回的痕迹。
- **锤线 / 吊颈线**：长下影线、实体极小。下影线是空头下砸被多头强力托起的抵抗痕迹。

### (2) 双根K线组合
- **吞没形态 (Engulfing)**：后一根K线的实体完全包裹前一根K线的实体（阳包阴为看涨，阴包阳为看跌）。信号强度极高，反转意图明确。
- **刺穿线 (Piercing Line)**：看涨吞没变体。阳线深入前阴线实体且收盘超过其 1/2 以上。
- **乌云盖顶 (Dark Cloud Cover)**：看跌吞没变体。阴线深入前阳线实体且收盘跌破其 1/2 以下。
- **孕线 (Inside Bar)**：第二根K线实体完全被前一根K线实体包含，反映趋势动能减速蓄势，信号强度较弱，必须依赖后续K线突破确认。

### (3) 三根或多根K线组合
- **启明星 (Morning Star)**：阴线 + 停顿星线 + 强势阳线（收盘超过第一根阴线中点）。极强底部反转形态。
- **黄昏星 (Evening Star)**：阳线 + 停顿星线 + 强势阴线（收盘跌破第一根阳线中点）。极强顶部反转形态。
- **红三兵 / 黑三兵**：
  - 前进模式：三根实体递增，多/空力量加速。
  - 停滞模式：三根实体递减，动能衰竭，面临回调。
  - 滞涨/滞跌模式：中间长、两头小，多空遭遇关键位阻力，动能枯竭。

## 3. K线形态的本质：价格运行轨迹与多周期切分
**核心定理**：K线形态的外观只是由观测周期切分导致的人工产物，其本质是价格随时间推进的几何博弈轨迹。

### (1) 跨周期等价转换
同一段冲高回落走势：
- 在 1小时（H1）图上：表现为一根带长上影线的**流星线 (Pinbar)**。
- 在 30分钟（M30）图上：切分为两根K线，表现为标准**看跌吞没形态**。
- 在 15分钟（M15）图上：切分为四根K线，表现为**黄昏星形态**。

### (2) 经典反转形态的微观结构
- **双重顶 (M头)**：等价于大周期的**黄昏星**或**双根连续流星线**。
- **双重底 (W底)**：等价于大周期的**启明星**或**双根连续锤线（双针探底）**。

交易者不应死记形态外观，而应透过K线结构直视内部的多空动能转换。
