# 裸K线交易法规则清单 (Execution Checklist)

在任何一笔实盘订单执行前，必须逐项核对并强制打钩。若有任何一票否决项，立即取消交易。

---

## 阶段一：环境与位置审查（一票否决）
- [ ] **周期合规**：当前图表级别是否 $\ge$ 4小时（H4）或 日线（Daily）？（严禁在低于H1周期寻找主信号）
- [ ] **基本条件 1（强关键位）**：当前位置是否处于大级别日线/4小时高低拐点、历史密集区或重要跳空缺口形成的水平关键带？
- [ ] **基本条件 2（明确波段极值）**：信号前是否具有至少连续 3 根以上明确单向趋势的K线，且信号自身处于波段最高点或最低点？

> **红线警示**：以上任一项为“否”，立即终止研判，严禁开仓！

---

## 阶段二：2+5 评级核算（细节加分）
需满足：两个基本条件全过（2） + 细节项得分 $\ge$ 2星（即总评级 $\ge 2+2$）：
- [ ] **细节 1（盘面显眼度）**：信号K线是否属于大象鼻子，全长幅度是否达到中阳/中阴线级别？（是 $\rightarrow$ +1星）
- [ ] **细节 2（伴随假突破）**：信号影线是否曾刺穿关键位/前高前低后暴力收回关键位内侧？（是 $\rightarrow$ +1星）
- [ ] **细节 3（左眼包容与幅度超越）**：信号实体是否完全落在前一根K线高低点内，且信号全长大于左眼全长？（是 $\rightarrow$ +1星）
- [ ] **细节 4（大级别顺势）**：信号方向是否顺应更大周期的主流趋势（如日线上涨趋势中的回调做多信号）？（是 $\rightarrow$ +1星）
- [ ] **细节 5（基础盈亏比合规）**：以破位入场测算，距离前方最近的关键位阻力，预期盈亏比是否 $\ge 1.5:1$？（是 $\rightarrow$ +1星）

**综合评级确认**：
- 评级结果：$\mathbf{2 + [ \quad ] \text{ 星}}$
- 是否达到 $2+2$ 及以上门槛？ [ ] 是 / [ ] 否（若否，放弃交易）

## 阶段三：入场与仓位测算
- [ ] **入场模式选定**：
  - [ ] 突破入场（突破信号极值挂单）
  - [ ] 收线入场（K线即将收盘且形态确认）
  - [ ] 回调入场（挂单于 50% 回调位）
  - [ ] 双挂单战术（突破单止损50% + 回调单止损影线后方，成交一撤一）
- [ ] **止损位刚性设定**：

  - 止损总点数：________ 点
- [ ] **止盈目标位设定**：
  - 目标关键位：________（向内让利 $5 \sim 15$ 点）

- [ ] **仓位计算**：
  $$\text{开仓手数} = \frac{\text{账户限定单笔风险金 (USD)}}{\text{点值} \times \text{止损点数}} = \underline{\hspace{3cm}} \text{手}$$

## 阶段四：持仓与出场纪律
- [ ] **撤离屏幕**：订单与止损止盈设置完毕后，关闭行情走势图，杜绝频繁盯盘。
- [ ] **发力跟踪**：观察右眼K线突破情况；若行情走势极度被动且滞涨/滞跌，评估减仓方案。
- [ ] **大单边追踪（三线战法）**：若属于日线流畅单边行情，启动三线战法，自第3根K线起动态将止损上移至最新3根K线极值，只收紧、不放大。
- [ ] **加仓铁律**：严禁在浮亏时加仓！若需金字塔加仓，必须等待行情出现下一个符合 $2+2$ 的全新信号，且前序持仓止损已移至新信号后方锁定利润。
- [ ] **风控熔断**：若该笔被止损打出，今日严禁在无信号时反手报复性开仓；若达到日内最大亏损额，直接离场休息。
